# 报销智能问答助手（纯前端单文件版）

员工在网页对话查询公司报销政策；政策**不存在 / 冲突 / 依据不足**时，自动转人工审核（前端提示 + 浏览器本地记录）。

## 特点
- **零依赖、零服务器**：单个 HTML 文件，双击用浏览器打开即可使用，无需 Python、无需安装、无需联网。
- 命中政策 → 带来源（citations）回答；冲突（如样例里 P 级差旅餐补 ¥200 vs ¥150）→ 转人工并说明原因；未知问题 → 转人工说明「暂无相关政策」。
- 转人工记录保存在浏览器本地（localStorage），可点右上角「转人工记录」查看。
- 可选「AI 设置」填入 OpenAI 兼容接口（API Base/Key/Model）即可切换大模型作答；留空则使用内置规则引擎离线作答，调用失败自动回退。

## 使用方法
直接双击打开 `reimbursement-qa.html`（或拖入浏览器）。

试三类问题：
- 命中：如「出差住宿标准是多少」「报销发票有什么要求」「市内外出打车能报销吗」
- 冲突：如「P级员工出差餐补每天多少」
- 未知：如「公司年假有几天」

## 替换真实政策
编辑 `reimbursement-qa.html` 中 `const POLICIES = [...]` 列表，换成贵司真实报销制度条目即可；冲突政策用 `conflict_with` 字段互相引用对方 id。

## 接入真实大模型（可选）
点右上角「AI 设置」填写：API Base URL、API Key、模型名。注意浏览器直连可能受跨域(CORS)限制，失败时自动回退规则引擎。
